# Ledger

An existing product whose design document names its tokens its own way: `paper` and `ink`, not the starter's
`surface` and `text`, a spacing scale of `sm` and `md`, and a radius it calls `card`. Only `accent` is a name the
starter reads too. `tests/projects.test.ts` starts a design in it, which keeps the starter's own tokens for the names
the document lacks.
