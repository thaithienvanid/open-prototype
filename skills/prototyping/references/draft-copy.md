# Draft copy

A new screen may need words the project's copy does not have. Then you write draft copy, so the work goes on, and the person keeps the choice of every sentence.

1. **Ask first.** Ask for the copy in the one message the skill's "What to ask the person" gives, so the person can give it instead.
2. **Write in the project's voice.** Take the voice and the words of the project's design document, and reuse each word its copy already has, such as its word for a retry.
3. **Keep it in the example data.** Every draft sentence sits in the example data, as all copy does, so the build and the pictures show it at its real length. The design holds no copy a screen shows, outside the example data.
4. **List each draft.** In the hand-off, list each key of the example data whose copy is a draft, with the sentence, for the person to approve or change.
5. **Wait for the person.** A draft becomes the project's copy only when the person approves it in their own words. Until then, call it a draft in every report.
